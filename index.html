Что такое Git

Git — это распределённая система контроля версий, созданная Линусом Торвальдсом в 2005 году для разработки ядра Linux. Она сохраняет историю изменений проекта и позволяет нескольким разработчикам работать над кодом одновременно.

В Git файлы проходят через три области:

1. Рабочая директория

Файлы, которые мы редактируем на компьютере

2. Индекс (staging)

Изменения, подготовленные к коммиту командой git add

3. Репозиторий

Сохранённая история проекта после git commit

Основные команды Git

Команда Назначение
git init Создать новый репозиторий
git status Показать состояние файлов
git add . Добавить изменения в индекс
git commit -m "..." Сохранить изменения с комментарием
git branch имя Создать новую ветку
git checkout имя Перейти в другую ветку
git merge имя Слить ветку с текущей
git log --oneline Показать историю коммитов
git push Отправить изменения на GitHub

Сборка и развертывание (CI/CD)

CI (Continuous Integration) — непрерывная интеграция: каждое изменение кода автоматически собирается и проверяется тестами.

CD (Continuous Delivery / Deployment) — непрерывная доставка: проверенная версия автоматически публикуется для пользователей.

Типичный процесс выглядит так:

Коммит → Сборка → Тестирование → Развертывание

Этот сайт — простой пример развертывания: после команды git push сервис GitHub Pages автоматически публикует новую версию страницы.
